## Design Context

### Users
This site is a personal portfolio for visitors evaluating creative and technical work in detail. The public audience includes people browsing projects, process notes, gallery entries, and future blog content, while the CMS is for a single owner managing that content.

### Brand Personality
Human, calm, refined. The interface should feel thoughtful, deliberate, and quietly confident rather than loud or corporate.

### Aesthetic Direction
Keep the dark visual language already established in the site and the supplied gallery mockup. The CMS should inherit the same restrained editorial tone instead of looking like a generic admin dashboard, while still staying practical for daily content work.

### Design Principles
1. Preserve continuity with the current portfolio instead of replacing it with a templated admin aesthetic.
2. Use spacious layouts, controlled contrast, and restrained accent color so content and imagery carry the experience.
3. Keep navigation obvious and interactions calm, with motion and decoration used sparingly and purposefully.
4. Prefer clear typography, durable forms, and predictable CRUD flows over flashy interface tricks in the CMS.
5. Treat media presentation as first-class: strong alt text, safe fallbacks, and graceful handling of mixed image proportions.
